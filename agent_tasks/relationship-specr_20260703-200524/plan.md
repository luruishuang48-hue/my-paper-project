# Multi-Agent Execution Plan

任务：在新面板上做一组探索性 specification curve，寻找除已知硬件、竞争者、下游部署、开源交互之外，是否还有稳定显著的关系或异质性。

时间：20260703-200524，北京时间。

## 规划阶段

1. 读取 `Analysis/processed/event_firm_panel.csv` 的字段、样本覆盖、关键标签分布。
2. 复核现有 `t9_main_regressions.csv` 与 `t9_robustness_matrix.csv`，避免重复报告已知结果。
3. 设计 specr 空间。维度包括因变量窗口、CAR 口径、控制变量组合、固定效应、样本切片、关系主效应、事件标签主效应和有限交互。
4. 预先设定筛选口径，区分探索性显著、稳健显著和可能由多重检验产生的偶然显著。

## 实施阶段

1. 主代理编写并运行 specr 脚本，输出完整规格结果、摘要表和候选关系清单。
2. 子代理 A 审阅 specr 设计，检查是否有明显遗漏、重复或不应纳入的规格。
3. 子代理 B 审阅输出，重点检查显著结果是否来自样本过小、单一事件、单一公司或变量共线。
4. 子代理 C 对候选结果做经济含义审阅，标出可以写进论文、只能作附录、应舍弃的结果。

## 审阅阶段

1. 用事件数、公司数、有效样本量、方向一致率和 FDR q 值审查所有候选。
2. 对主要候选做 leave-one-year、leave-one-event-type 或关键样本切片核验。
3. 检查是否与现有 T9 结果矛盾；如矛盾，优先给出原因而不是强行解释。

## 修订阶段

1. 根据审阅意见补跑必要的窄口径核验。
2. 形成最终报告 `specr_findings.md`。
3. 保存机器可读输出，至少包括完整规格表、候选摘要表和审阅备注。

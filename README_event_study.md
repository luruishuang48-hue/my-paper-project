# tools/ —— 旧工作流工具的修正版

**定位**：论文的 CAR 以 `Analysis/scripts/build_event_firm_panel.py` 为准。
本目录是旧版逐公司 Excel 工作流（`事件研究法.py` + `三因子事件研究.py`）的
修正替代品，供沿用该数据格式的协作者使用——一个脚本同时输出市场模型与
FF3 两套 CAR。

```bash
python3 event_study.py --data-dir /path/to/公司xlsx文件夹
python3 event_study.py --data-file GOOGL.xlsx --events 自定义事件.csv
```

数据列要求：`date, share_earn, market_earn`（必需）+ `smb, hml, rf`
（可选，缺失则只算市场模型）。事件表默认读流水线核证日期，自定义表需含
`event_id, date` 两列。

## 相对旧版的修正

| 旧版问题 | 本版处理 |
|---|---|
| 窗口为对称日历日（"car20" 实为 ±20 日历日 ≈±14 交易日且逐事件不等长） | 全部按交易日位置索引：事件后 [0,+w]，事件前 [-10,-2] 单独报告 |
| 估计窗 [-130,-11] 日历日（≈80 交易日）且与事件窗重叠 10 天 | 默认 [-200,-11] 交易日，与报告窗零重叠（启动断言），最少 120 观测 |
| 事件日逢休市 day 0 静默消失 | 顺延至下一交易日并输出 `day0_rolled` 标记 |
| FF3 中 rf/smb/hml 百分点与小数收益混用 | 量级自动检测统一为小数（rf 有专门规则），转换留痕，存疑即拒跑 |
| 每公司手工改代码贴日期 | 批量扫描文件夹 + 事件表驱动 |

## 验证记录（2026-07-13，合成 GOOGL 数据同 schema 实测）

- 市场模型 CAR 与论文面板 125 个事件**逐一比对，最大绝对差 1.1e-16**（机器精度）；
- 假日顺延 4/4 正确（感恩节、MLK、两个周六官方日），滚动后 CAR 与面板一致；
- 单位检测对百分点口径的 Mkt-RF/smb/hml/rf 全部正确触发；
- FF3 CAR 与面板差 ≤0.8pp 属口径差异（本工具用 SPY−rf 作市场因子，
  面板用 Ken French Mkt-RF 即 CRSP 全市场组合），非误差。
